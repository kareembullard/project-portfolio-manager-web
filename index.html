📊 Project Portfolio Manager

11 active initiatives tracked with budgets, health scoring, financials, analytics, a project wiki, and an offline Smart Assistant.

This is a portfolio demo. All data (projects, alerts, tasks, financials) is fictional sample data, seeded on first load. Everything is editable — add/edit/delete projects, tasks, and alerts, adjust portfolio targets. Edits save to your browser only (localStorage); nothing is ever sent to a server. Use Reset in the toolbar to restore the original demo data.
